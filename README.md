# Smart Torrentio

إضافة Stremio محلية تعمل كطبقة ترشيح أمام Torrentio: تستقبل نتائج البث، تستبعد وسوم الدبلجة واللغات المحظورة وإصدارات التصوير الرديء، ترتب الباقي، وتعرض الترجمات العربية من إضافة OpenSubtitles v3.

## التشغيل

يتطلب Node.js 18 أو أحدث. لا توجد اعتماديات تشغيل خارجية؛ `npm install` لا ينزّل حزمًا.

```sh
npm install
npm start
```

افتح `http://localhost:7000/configure` لإعداد حد البذور، عنوان Torrentio، وقائمة الكلمات المحظورة. الصفحة تنتج رابط manifest بالإعدادات المشفرة داخل المسار. الإعدادات لا تتطلب قاعدة بيانات، وتعمل بعد إعادة تشغيل الخادم.

لإضافة الإعداد الافتراضي محليًا إلى Stremio استخدم:

```text
stremio://localhost:7000/manifest.json
```

أو الصق `http://localhost:7000/manifest.json` في شاشة إضافة الإضافات. على الهاتف أو التلفاز، `localhost` يشير إلى الجهاز نفسه؛ شغّل الخادم على الشبكة المحلية واستخدم عنوان جهاز الكمبيوتر، أو انشره على عنوان HTTPS عام.

## إعداد البيئة

انسخ `.env.example` إلى `.env` عند تشغيلك عبر أداة تدعم ملفات البيئة. Node لا يقرأ `.env` تلقائيًا من دون حزمة إضافية؛ يمكن ضبط المتغيرات في الطرفية. في PowerShell:

```powershell
$env:PORT='7000'
$env:TORRENTIO_URL='https://torrentio.strem.fun/lite'
$env:MIN_SEEDERS='15'
node server.js
```

المتغيرات: `PORT` (7000)، `TORRENTIO_URL` (عنوان إعداد Torrentio الذي يسبق `/stream/...`)، `MIN_SEEDERS` (15)، `UPSTREAM_TIMEOUT_MS` (8000)، `SUBTITLES_URL` (OpenSubtitles v3)، و`CACHE_TTL_MS` (600000). خادم البيئة يقرأها عند بدء التشغيل. قائمة الحظر الافتراضية في `config.js` ويمكن تغييرها من صفحة الإعداد.

## النشر المجاني

يمكن تشغيله على أي خدمة تستضيف تطبيقات Node.js وتوفر عنوان HTTPS عامًّا. إذا كان حسابك يوفر خدمة ويب مجانية مثل Render، أنشئ Web Service من مجلد المشروع، واستخدم:

- Build command: `npm install`
- Start command: `npm start`
- Environment: `TORRENTIO_URL=https://torrentio.strem.fun/lite` و`MIN_SEEDERS=15`

بعد النشر، افتح `https://YOUR-SERVICE/configure` ثم انسخ رابط manifest الناتج إلى Stremio. قد تنام بعض الخطط المجانية عند الخمول؛ عندها قد يتأخر أول طلب إلى أن يستيقظ الخادم. تحقق من الخطة المتاحة في مزود الاستضافة قبل الاعتماد عليها للتلفاز.

## السلوك والقرارات

- الموارد: `stream` و`subtitles`، للأنواع `movie` و`series`، وبادئات IMDb `tt`.
- طلبات Torrentio وOpenSubtitles لها مهلة 8 ثوانٍ افتراضيًا. الفشل أو الاستجابة غير الصالحة يعيد قائمة فارغة بدل إسقاط الخادم.
- المرشح يقرأ الاسم والعنوان واسم الملف والوصف، ويزيل وسوم اللغات/الدبلجة الموجودة في `config.js`، وكذلك CAM وTS وHDTS وSCR. دقة اللغة غير مضمونة لأن المزودين لا يضعون الوسوم بطريقة موحّدة؛ لذلك هذه تصفية بالاسم وليست تحليلًا للمسار الصوتي.
- أقل من 15 بذرة يُحذف افتراضيًا. إذا لم يبق أي مصدر بعد حد البذور، يعيد المرشح أفضل خمسة من المصادر النظيفة حسب البذور. المصادر التي حُظرت بسبب لغة أو CAM/TS/SCR لا تدخل في هذا الرجوع.
- الترتيب: نتائج Debrid المخزنة مؤقتًا أولًا عند وجود إعداد Debrid في عنوان Torrentio؛ ثم الدقة 2160p، 1080p، 720p، وأخيرًا غير المعروفة؛ ثم عدد البذور تنازليًا. تفضيل `English`/`eng`/`original` أو غياب وسم لغة يُستخدم لكسر التعادل بعد الدقة والبذور حتى لا يتجاوز معيار الترتيب الأساسي.
- كائن البث الأصلي محفوظ مع `infoHash` و`fileIdx` و`url` و`behaviorHints`. يتغير حقل `name` فقط ليعرض وسمًا مختصرًا قابلًا للقراءة.
- الترجمات الممررة هي `ara` فقط، وتزال التكرارات حسب الرابط أو المعرّف، ثم ترتب حسب عدد التنزيلات والتقييم عند توفرهما. لا يمكن للخادم ضمان جودة الترجمة نفسها؛ هذه البيانات تأتي من OpenSubtitles.
- الذاكرة المؤقتة 10 دقائق وتعمل داخل نسخة الخادم الحالية فقط.
- مسار `/configure` يكوّد الإعدادات في URL كي يكون لكل رابط تثبيت إعداد مستقل. لا تضع مفاتيح API أو أسرارًا في الحقول أو رابط التثبيت.

## الاختبار

```sh
npm test
```

الاختبارات تتحقق من التحليل والترتيب والمرشحات والرجوع وحقول التشغيل. يمكن فحص عناوين حقيقية بعد تشغيل الخادم:

```sh
curl http://localhost:7000/stream/movie/tt0133093.json
curl http://localhost:7000/stream/series/tt0944947%3A1%3A1.json
curl http://localhost:7000/subtitles/movie/tt0133093.json
```
